# NaviField Open

[English](README.md) · **简体中文**

**为你的仿真问题找到可用的开源求解路线。**

让你的 coding agent 成为你的仿真专家。带上你的研究课题或产品问题，先找适用的开源模型。必要输入齐备、本机有求解器时，让助手实际求解，并用参考值核对结果。

把下面这段话复制给 Codex、WorkBuddy 或 DeepSeek Harness，填上你的问题。

```text
请按 NaviField Open 仓库根目录的 AGENT.md 处理我的问题。
https://github.com/navifield/navifield
查明能算什么、依据是什么。查不到，按目标量或工况复查。
缺关键输入先问我；条件齐备就本机求解，读回结果并核对。
需要新开发时，先展示公开草稿，问我是否同意发布。
我的问题或论文：【填在这里】
```
