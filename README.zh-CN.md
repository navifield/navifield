# NaviField Open

[English](README.md) · **简体中文**

**为你的仿真问题找到可用的开源求解路线。**

让你的 coding agent 成为你的仿真专家。从研究课题或产品需求出发，一起判断用什么工具、需要哪些输入、怎样验证结果。

在自己的工作区打开 Codex、WorkBuddy 或 DeepSeek Harness，复制下面的提示词，把最后的占位文字换成你的问题或论文链接。

```text
请按 NaviField Open
（https://github.com/navifield/navifield）
的 AGENT.md 评估我的问题。
找一条有依据的开源路线，核对现有
算例能否覆盖我的工况和目标量。
能复用就帮我算并校核，缺参数先问我，
需要新开发时说明缺口并问我是否
愿意发 GitHub Issue。
我的问题或论文链接是：【填在这里】
```
