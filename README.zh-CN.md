# NaviField Open

[English](README.md) · **简体中文**

**为你的仿真问题找到可用的开源求解路线。**

让你的 coding agent 成为你的仿真专家。从研究课题或产品需求出发，一起判断用什么工具、需要哪些输入、怎样验证结果。

在自己的工作区打开 Codex、WorkBuddy 或 DeepSeek Harness，复制下面的提示词，把最后的占位文字换成你的问题或论文链接。

```text
请使用 NaviField Open
（https://github.com/navifield/navifield），
按仓库的 AGENT.md 查询我的问题。
先告诉我有哪些可参考的开源求解路线、
依据是什么、还缺哪些条件。
我的问题是：
【在这里写仿真需求或粘贴论文链接】
```
